**八通道尺寸测量上位机系统（TICP）**　　上位机开发　　2026.11 - 至今

**技术栈：**C# / .NET 8 / WinForms / SunnyUI / NModbus / Modbus RTU / SQLite / ScottPlot 5 / SkiaSharp

**项目描述：**面向八通道尺寸测量的上位机，基于 NModbus 通过串口读取下位机 8 路寄存器数据，完成标定换算、阈值判定、实时显示与数据入库；提供按时间和产品查询、合格率统计、CSV 导出与历史趋势曲线功能。

**项目地址：**https://github.com/yijiedemotu/WinFormsProject.git

**个人职责：**

1. 基于 C# / .NET 8 与 WinForms、SunnyUI 搭建项目框架，封装页面切换方法，完成数据测量、查询统计、趋势曲线、阈值设置四个页面的布局与控件绑定。
2. 基于 NModbus 封装 Modbus RTU 通信类，实现串口连接、8 路保持寄存器批量读取与字节序转换；使用 Task + CancellationToken 做 1s 周期异步轮询，加入断线重连、超时设置与日志限流。
3. 实现两点线性标定与阈值判定，用 bool? 区分合格、超差和未标定；采集线程写入原始数据与物理量数组，保存时取原始值快照重新计算后写入数据库。
4. 使用 SQLite 建表并实现参数化增删改查，针对旧版本库缺列做表结构升级；实现按时间、产品的条件查询、合格率统计与 CSV 导出。
5. 基于 ScottPlot 5 绘制历史趋势曲线，处理中文字体显示问题；处理跨线程访问控件、页面切换句柄重建导致采集中断等问题。
