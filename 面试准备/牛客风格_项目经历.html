八通道尺寸测量上位机系统（TICP） 上位机开发 2026.11 - 至今
项目简介：八通道尺寸测量上位机，面向设备采集与质量判定场景。基于 Modbus RTU 从下位机批量读取 8 路原始计数，经两点线性标定换算为物理量后按阈值做三态判定，实时驱动 8 张通道卡片与指示灯；支持 SQLite 入库、条件查询、合格率统计、CSV 导出与历史趋势曲线，独立走通「设备采集 → 标定判定 → 数据存储 → 质量追溯」完整闭环。
项目地址：https://github.com/yijiedemotu/WinFormsProject.git
技术栈：C#/.NET 8、WinForms、SunnyUI、NModbus、SerialPort、Microsoft.Data.Sqlite、ScottPlot、SkiaSharp、System.Text.Json、Git
技术亮点：
  • 基于 NModbus + SerialPort 实现 Modbus RTU 采集，批量读取 8 路保持寄存器（0x03），支持 ABCD / CDAB / BADC / DCBA 四种字节序转换，覆盖 float / double 等多类型解析。
  • 采用 Task.Run + CancellationTokenSource 异步轮询替代 WinForms.Timer，避免串口阻塞 UI 线程；实现 3s 间隔断线自动重连，以 volatile manualDisconnect 压制用户主动断开后的误重连，异常与超差日志按 10s 限流。
  • 设计 bool? 三态质量判定，区分「合格 / 超差 / 未标定」，避免未标定通道被误判为不合格；整体结论按「超差 > 未标定 > 合格」聚合，并记录具体超差通道号。
  • 以 oriData 原始快照重新判定后再入库，不信任可能因隐藏通道、切页而过期的界面显示值，保证 SQLite 中数据与判定结果同源；封装不依赖 WinForms 的纯逻辑判定服务，可脱离窗体与串口验证。
  • 实现 SQLite 幂等升级与 SQL 内聚合统计：通过 PRAGMA table_info 探测旧库列并 ALTER TABLE 补列、回填历史数据，无需删库即可升级；用 SUM(CASE WHEN) 在数据库侧计算合格率，避免全表载入内存。
  • 基于 ScottPlot 5 / SkiaSharp 实现历史趋势曲线，通过 Fonts.Detect + plot.Font.Set + Legend.FontName 修复中文字体缺字显示为方框的问题，并采用离屏 Render 出 PNG 完成无窗体验证。
  • 处理 WinForms 生命周期与跨线程细节：跨线程更新统一 BeginInvoke + IsDisposed / IsHandleCreated 校验；采集任务与定时器只在 Disposed 停止（切页换 Parent 会重建句柄并触发 HandleDestroyed），Load 加幂等保护，规避切页后采集永久停止。
